# Asset generators (original art and sound for LAST SIGNAL)

Every image and sound in the game was made by these scripts (no downloads, no samples).
They are kept here so the assets can be regenerated or tweaked. They are **not** part of the game build
(`tools/*` is excluded from exports).

Requirements: Python 3 with Pillow (`pip install pillow`); for audio also numpy, scipy and ffmpeg (for .ogg).
Run from the project folder, passing the project folder as the output (`.`):

| Script | Makes |
|--------|-------|
| `make_world.py .` | `assets/tiles/tiles.png`, `roof.png`, vehicles, containers, safehouse furniture, item icons, `icon.png` |
| `make_chars.py .` | `assets/sprites/player.png`, `walker.png`, `walker_eyes.png`, `bat.png`, `pistol.png`, `muzzle_flash.png` |
| `pixel_font.py assets/fonts/last_signal_pixel.png` | the pixel font sheet |
| `make_audio9.py .` | Phase 9 sounds (`assets/audio/sfx/`) and the music/ambience loops (`assets/audio/music/*.ogg`) |
| `make_sfx.py assets/audio/sfx`, `make_sfx5.py ...`, `make_sfx7.py ...` | the earlier sounds (Phases 2, 5, 7). Careful: `make_sfx.py` would overwrite the 6 sounds regenerated by `make_audio9.py`; run `make_audio9.py` after it. |

The character sheets have a fixed layout that `scenes`' SpriteFrames rely on (see `PLAYER_ANIMS` / `WALKER_ANIMS`
in `make_chars.py`; the same lists are used when the frames resource is built). Keep them in sync if you add frames.
